# 控卡策略详解（nutrition-strategy.md）

> 本文件为 Skill 的「营养判定知识库」，提供餐段热量参考区间、替换优先级与钠警戒线。
> ⚠️ 以下为通用成年人参考值，**非医学 / 营养专业标准**，个体差异大；本 Skill 输出不构成营养或医疗建议。具体饮食请遵医嘱或注册营养师。

## 一、餐段热量参考区间（单餐）

| 餐段 | 参考区间 (kcal) | 说明 |
|---|---|---|
| 早餐 | 300 - 500 | 侧重蛋白与膳食纤维 |
| 午餐 | 500 - 850 | 全天主餐，可包容套餐 |
| 晚餐 | 500 - 800 | 略低于午餐，控脂 |
| 加餐 | < 200 | 仅作能量补充 |

> 判定逻辑：当前订单总热量 ÷ 该餐段上限 = 占比。轻食 (<50%) / 均衡 (50%-100%) / 偏高 (100%-120%) / 超标 (>120%)。

## 二、宏量营养参考（单餐）

- 蛋白质：20 - 30 g（减脂期可偏上限）
- 脂肪：占全天能量 20% - 35%
- 碳水：占全天能量 50% - 65%
- 钠：单餐 < 800 mg 较友好；全天 < 2000 mg

## 三、替换优先级（按热量差从大到小）

1. 含糖饮料 → 零度可乐 / 水（最大热量差，约 -100~150 kcal）
2. 薯条 → 玉米杯 / 苹果（约 -120~160 kcal，钠同步下降）
3. 炸制单品 → 板烧 / 烤制（看具体单品）
4. 去酱 / 去芝士（脂肪 -5~10 g）
5. 套餐升杯 → 避免，控制分量

## 四、钠警戒线

- 单餐钠 < 800 mg：友好
- 单餐钠 800 - 1200 mg：偏高，控盐人群注意
- 单餐钠 > 1200 mg：超标，建议替换或去酱

## 五、目标化策略

- 减脂：优先 1 / 2 / 3，叠加去酱；用 `list-nutrition-foods` 真实值核对。
- 控盐：避开培根 / 芝士 / 酱料加重项，优先原味与去酱。
- 均衡：补足蛋白（加蛋 / 鸡肉类）与蔬菜（玉米杯 / 沙拉）。
